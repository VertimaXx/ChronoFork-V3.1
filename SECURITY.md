# Reporting security issues

This contact-checking library is not a complete anti-cheat or movement validator. Review the [trust and timing boundaries](docs/math-and-limits.md) before reporting an integration issue.

If GitHub's **Security → Report a vulnerability** is enabled for this repository, use it for exploitable issues. Otherwise send a minimal, non-sensitive reproducer through the maintainer's available contact channel, or open an issue describing the affected boundary without a live-game exploit or private player data. No private reporting address or response-time guarantee is asserted here.

Do not report an attack against a third-party game as authorization to test it. A trust label does not validate client movement. Rewind policy, replay prevention and exactly-once gameplay effects remain game-owned.
