116 entries

Core messages use unchanged Core 3.1 Help. Connector 3.2 adds its own explanations; shared codes are labeled by layer. Use Connector.Explain or Core.Explain as appropriate. Keep exact codes in logs. Unknown codes remain unknown.

Word · authoritative

Server decides

The server makes or checks the value used to decide a hit. A player cannot make a position valid just by sending it.

Example: A tackle uses a position your server movement code has checked.

Word · server

Server

The computer running the shared game rules for all players. In Studio Play, you can switch between the server and a player's client.

Example: The server decides who gets the ball.

Word · client

Client

One player's running copy of the game. It handles input, the camera and what that player sees.

Example: A LocalScript reads the tackle button.

Word · history

Saved past positions

A short list of earlier positions, hitboxes and game values, with the time of each record. Chrono keeps these in memory and later removes old records.

Example: Keep the last 0.6 seconds so a check can use an earlier position.

Word · snapshot

One saved record

The position, hitboxes and game values of one object at one time.

Example: At time 10.2, the ball was here and the player was on team 2.

Word · actor

Tracked object

Anything Chrono checks: a player, a ball, an NPC or another game object. It does not have to be a character.

Example: Register the football as kind ball.

Word · provider

Function that supplies data

A function you write. Chrono calls it to get an object's position, hitboxes and game values.

Example: Read a ball position calculated by your server and return a sphere around it.

Word · adapter

Connection to your game code

A small piece of code that connects Chrono calls to the scripts your game already uses. Bindings is the generated module for these connections.

Example: When your move script accepts a tackle, start a Chrono action.

Word · bindings

Connections to your game code

The functions that connect your players, moves and rules to Chrono. The setup creates a Bindings module for you to edit.

Example: Call Bindings.Track when your game adds a player.

Word · callback

Function given to another function

A function Chrono calls when it needs data or a rule result. The function must finish without task.wait or waiting for an event.

Example: eligible = function(source, target) return source.team ~= target.team end

Word · root

Reference position

The main position and direction from which an object's hitboxes are measured. It is a CFrame value; it need not be a part named HumanoidRootPart.

Example: For a ball, its center can be the root.

Word · cframe

Position and direction (CFrame)

A Roblox value that stores both where something is and which way it faces.

Example: CFrame.new(0, 0, -3) places a local hitbox 3 studs in front.

Word · local space

Relative to an object

Measure a shape from the object's reference position and facing direction. It moves with that object.

Example: A tackle box stays 3 studs in front of the player.

Word · world space

Position in the map

Measure a shape in the map's coordinate system, rather than from one object.

Example: A provider returns the ball hitbox at the ball's map position.

Word · state

Game values saved with a position

Small values your hit rules need at that time. Use true/false, numbers or short text. Do not put Instances or nested tables here.

Example: {active=true, team=2, invulnerable=false}

Word · eligible

Allowed by your game rules

A target can count only if the rules you supply allow it. Your game must also check its current rules before applying the result.

Example: A teammate or an invulnerable player may be excluded.

Word · hitbox

Shape used to check contact

An invisible shape your gameplay uses to decide whether a move reaches an object. It may be simpler than the visible model.

Example: A sphere can represent a football.

Word · capsule

Cylinder with round ends

A shape like a cylinder with a half-sphere at each end. Height includes both round ends and must be at least twice the radius.

Example: A simple body hitbox can have radius 1.5 and total height 5 studs.

Word · radius

Center-to-edge distance

The distance from the center of a ball or circular part to its edge. Diameter is twice this value.

Example: Radius 1.5 means a ball is 3 studs wide.

Word · ray

Line check

A line from a start point to an end point. It has no thickness.

Example: A straight instant-shot check can use a ray.

Word · sweep

Shape checked along a path

Check a ball all along a straight line, rather than only at its final position. Other objects are held at the one saved time being checked.

Example: A thick straight attack can use a swept sphere.

Word · interpolation

Estimate between saved positions

If the requested time lies between two records, Chrono estimates a position between them. It refuses to guess across a large gap or an uncertain change.

Example: Records at 10.0 and 10.05 can estimate a pose at 10.025.

Word · coverage

Enough saved data for the requested time

Chrono has suitable records around that time and its time, change and shape checks pass. This does not prove your supplied positions were honest.

Example: A covered check with zero contacts means a checked miss.

Word · rewind

Check an earlier position

Use saved records from before the latest update. This is off by default and needs a timing rule supplied by your server.

Example: Your approved timing rule may allow checking 0.08 seconds earlier.

Word · lag compensation

Use earlier data to account for delay

A game policy that can let an input use an earlier position because messages took time to travel. Chrono does not choose a fair time automatically.

Example: Decide how much delay your game allows before rejecting an old request.

Word · latency

Message travel delay

The time a message takes to travel. Ping usually measures a round trip, not one direction.

Example: 50 ms each way adds about 100 ms to a round trip.

Word · epoch

Position-record version

A number that changes when tracking is reset. Older records cannot silently be used after that reset.

Example: A respawn starts a new version of the player's position records.

Word · discontinuity

Approved tracking reset

A real change where earlier positions must no longer connect to later ones. Your game reports it with Discontinuity after approving the change.

Example: Teleport, respawn, or a change in who simulates an object.

Word · quarantine

Pause one object's recording

Chrono stops using an object's records after its data function fails or returns bad data. Fix the cause, report the approved reset, then record again.

Example: Do not reset tracking repeatedly just to hide a faulty data function.

Word · network ownership

Who calculates Roblox physics

Roblox can let a player's client calculate an object's physics. Reading that result on the server alone does not prove it was a legal move.

Example: Your server still needs to check player movement used to decide competitive hits.

Word · stud

Roblox distance unit

A unit for size and distance in Roblox Studio.

Example: A default Part is 4 studs wide along its X axis.

Word · hz

Updates per second (Hz)

How often something is updated each second. Chrono's rate setting sizes its storage; your script still calls Capture.

Example: 60 Hz means 60 updates in one second.

Word · handle

Move reference returned by Chrono

The value BeginAction returns after it accepts a move. Keep it and pass it to Query and EndAction. Do not create your own table as a replacement.

Example: local move, reason = chrono:BeginAction(playerId, profile)

Word · capture

Save one update

Capture asks each registered object's data function for a position record. Your game calls it after all participating objects finish the same server update.

Example: chrono:Capture()

Word · query

Check a move

Query checks the move reference you kept from BeginAction. It returns allowed contacts or a reason explaining why the check could not complete.

Example: local result = chrono:Query(move)

Word · profile

Settings for one move

A plain Luau table describing the shape, target types, timing, target limit and rules for a move.

Example: The generated Actions.Contact table is one profile.

Word · contact

One returned target

A tracked object whose saved hitbox touched the move's shape and passed the supplied rules. Your game still decides whether to apply its current result.

Example: result.contacts[1].id is the first returned object id.

Word · active window

Time when the move may hit

The time from opens to closes, counted after your server starts the move.

Example: opens=0.12 and closes=0.35 allow checks from 120 to 350 ms after the start.

Word · id

One object's name in your code

A stable short text label for a particular registered object. Keep it unique while that object is tracked.

Example: player-12 is an id; player is its kind.

Word · kind

Group name for similar objects

A short text label for an object type. A move's targets list uses these labels to choose which groups to check.

Example: Register a ball with kind='ball'; use targets={'ball'} to check that group.

Word · unverified

Data not approved for hits

The default label for positions whose server-side calculation or validation has not been established. Chrono refuses gameplay checks that need them.

Example: Selecting a Part in Studio creates only an unverified reference.

Word · serverSimulated

Data calculated by your server

Use this trust label only when your own server code actually calculates the positions used for hit checks.

Example: A server-owned ball simulation supplies its position.

Word · serverValidated

Data checked by your server

Use this trust label only after your server actually verifies the supplied positions and hitboxes against the rules your game requires.

Example: Your existing movement checks reject impossible client moves before their data reaches Chrono.

Word · ModuleScript

A reusable code file

A Roblox code file that returns a value when another script calls require on it. Installing the generated main module does not automatically connect it to your game.

Example: local startChrono = require(game.ServerScriptService.ChronoV3Integration)

Word · boolean

True or false

A value with only two choices. Useful for saved rules such as whether a player is active or invulnerable.

Example: state = {active=true, invulnerable=false}

Word · hitscan

Instant line check

Check a straight line immediately. There is no simulated bullet flying along that path over later frames.

Example: The Instant line check preset creates a ray-shaped query.

Word · source

Object doing the move

The registered object whose saved position and facing direction place the move's hitbox.

Example: The tackling player is the source; the player or ball being checked is a target.

Word · target

Object the move may touch

A registered object of a kind listed in the move's targets. Its saved hitbox is checked against the move.

Example: A kick can target the ball kind.

Word · jitter

Changing message delay

Messages do not all take the same time to arrive. This makes updates arrive at uneven intervals.

Example: Studio's Network Simulator can add different jitter in each direction.

Word · packet loss

Dropped network packets

Some small pieces of network data do not arrive. Reliable messages can be resent, which adds delay; unreliable updates may stay missing.

Example: 0.5% means half of one percent, not 50%.
